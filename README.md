# Publiyep Acacías - Página web profesional

Este ZIP contiene una propuesta de página web estática para Publiyep Acacías.

## Archivos incluidos

- `index.html`: estructura principal de la página.
- `css/styles.css`: estilos, diseño responsive, colores y animaciones.
- `js/main.js`: menú móvil, animaciones y formulario que abre WhatsApp.
- `assets/`: logo en SVG, favicon, imagen hero e imagen OG para redes.

## Cómo usarla

1. Descomprime el ZIP.
2. Abre `index.html` en el navegador para verla localmente.
3. Para subirla a hosting, carga todos los archivos en la carpeta pública del sitio.
